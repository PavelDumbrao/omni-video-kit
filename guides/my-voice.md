# Свой голос в ролике: ElevenLabs speech-to-speech

Инструкция агенту. Ролик из Omni говорит похожим голосом. Здесь меняем голос на настоящий голос человека через ElevenLabs Voice Changer (speech-to-speech). Интонации, паузы и длина остаются, меняется только тембр. Картинку не трогаем.

Веди человека за ручку, по одному шагу, коротко и по-русски.

## Что человек делает сам (5 минут)

Спроси, что из этого уже есть, и проведи по недостающему:

1. **Аккаунт и тариф.** https://elevenlabs.io → вход → тариф **Starter** ($1 первый месяц). На бесплатном тарифе клонировать голос нельзя.
2. **Свой голос.** Voices → создать голос → **Instant Voice Clone**. Загрузить 1–2 минуты своей чистой речи: диктофон телефона, тихая комната, без музыки и чужих голосов. Сохранить голос.
3. **Ключ.** В меню слева **Developers → API Keys** → создать ключ. Если спросит про права — включить **Speech to Speech** и **Voices** (чтение). Скопировать ключ.

Ключ человек вставляет в файл `.env` в папке набора строкой `ELEVENLABS_API_KEY=...` (рядом с `YICIYUANG_API_KEY`). Если прислал ключ в чат — запиши его в `.env` сам и больше нигде не повторяй.

## Что делаешь ты

Нужны `curl`, `python3` и `ffmpeg` (нет ffmpeg — поставь, см. `AGENTS.md`). Команды ниже для macOS и Linux; на Windows перепиши их под PowerShell.

**1. Загрузи ключ и найди голос человека.**

```bash
set -a; . ./.env; set +a
curl -s https://api.elevenlabs.io/v1/voices -H "xi-api-key: $ELEVENLABS_API_KEY" \
  | python3 -c "import json,sys; [print(v['voice_id'], '|', v['name'], '|', v['category']) for v in json.load(sys.stdin)['voices'] if v['category'] != 'premade']"
```

Покажи человеку список и спроси, какой голос взять. Пусто — значит голос ещё не склонирован (шаг 2 выше).

**2. Вытащи звук из готового ролика.**

```bash
ffmpeg -y -i ролик.mp4 -vn -c:a libmp3lame -q:a 2 ролик_звук.mp3
```

**3. Смени голос.** Вместо `VOICE_ID` — выбранный голос.

```bash
curl -s -o ролик_голос.mp3 -w "%{http_code}\n" -X POST \
  "https://api.elevenlabs.io/v1/speech-to-speech/VOICE_ID?output_format=mp3_44100_128" \
  -H "xi-api-key: $ELEVENLABS_API_KEY" \
  -F model_id=eleven_multilingual_sts_v2 \
  -F remove_background_noise=true \
  -F audio=@ролик_звук.mp3
```

Должно вернуться `200`. Иначе открой `ролик_голос.mp3` как текст — там причина (таблица ниже).

**4. Вставь новый звук в видео, картинку не перекодируй.**

```bash
ffmpeg -y -i ролик.mp4 -i ролик_голос.mp3 -map 0:v -map 1:a -c:v copy -c:a aac -shortest ролик_мой_голос.mp4
```

**5. Проверь и покажи.** Сверь длительности (`ffprobe -v error -show_entries format=duration -of csv=p=0 файл`) — новый ролик не короче исходника больше чем на 0,1 с. Открой человеку оба файла рядом, чтобы он сравнил.

## Цена

Смена голоса считается по длине звука: около 1 000 кредитов ElevenLabs за минуту, ролик 10 с ≈ 170 кредитов. Остаток кредитов виден в профиле ElevenLabs.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| `401`, `invalid_api_key` | ключ скопирован не целиком — создать новый |
| `403`, `missing_permissions` | у ключа не включено Speech to Speech — включить или создать ключ заново |
| `voice_not_found` | взят не тот `voice_id` — повторить шаг 1 |
| `quota_exceeded` | кончились кредиты — пополнить тариф |
| голос не похож | перезаписать образец: 2–3 минуты, ближе к микрофону, тише фон, и сделать новый голос |
| голос «плывёт» на шуме | убедиться, что `remove_background_noise=true` |
| файл больше 5 минут | порезать звук на куски до 5 минут, сменить голос в каждом и склеить |

## Правила

- Ключ не печатай, не коммить `.env`, не вставляй в код.
- Голос — только свой или с согласия владельца.
- Сначала покажи человеку результат, потом говори «готово».
