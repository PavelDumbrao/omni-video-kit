# Регистрация на 创艺坊 (Yiciyuang) и ключ

Сайт китайский, интерфейс на китайском (в браузере включите «Перевести страницу» — так проще).

1. Откройте https://newapi.yiciyuang.com/register?aff=W3q1 (форма регистрации, **注册**). Нужны логин, пароль и почта: на почту придёт код (**验证码**), введите его.
2. Войдите → **控制台** (консоль).
3. **令牌** / **令牌管理** (токены) → **添加令牌** (создать токен). Название любое, группа `default`, срок и лимит — без ограничений или как удобно. Скопируйте ключ `sk-...`.
4. В папке набора создайте файл `.env` (образец — `.env.example`):
   ```
   YICIYUANG_API_KEY=sk-ваш-ключ
   ```
   Ключ никому не показывайте и не выкладывайте на GitHub (`.env` уже в `.gitignore`).
5. Пополнение: **钱包** / **充值** (кошелёк). Цены на сайте в юанях (¥1 ≈ 12 ₽). Для первых проб хватит ¥10–20: один запуск стоит ¥0,75–0,82.
6. Проверка: `python3 scripts/omni.py check` → «Ключ работает».

Расход и историю запусков видно в консоли: **日志** (журнал) и **任务** (задачи). Отказ модерации и ошибка до старта генерации денег не стоят.
