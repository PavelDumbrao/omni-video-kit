# Google Omni через Yiciyuang: продление и перерисовка видео

Проверено автором набора в ноябре 2026 на десятках платных запусков. Цены в юанях (¥1 ≈ 12 ₽).

## Три модели
| Модель | Что делает | Вход | Выход | Цена |
|---|---|---|---|---|
| `omni-extend-20s` | **Продлевает** видео: продолжает сцену, движение и голос | видео ≤ 12,0 с (+ фото лица по желанию) | копия входа + ~10 с нового (вход 10 с → ~20 с) | ¥0,75 (~9 ₽) |
| `omni-fast-v2v` | **Перерисовывает** видео по запросу: одежда, фон, стиль | видео ≤ 10 с (длиннее — обрежет) + образец по желанию | 1280×720, та же длина | ¥0,82 (~10 ₽) |
| `omni-fast-no-water` | Новый ролик **из фото и текста**, говорит реплику дословно. С двумя кадрами — сцена **от первого кадра к последнему** | фото или два кадра (по желанию) + текст | 10 с, 1280×720, без значка | ¥0,75 (~9 ₽) |

Все три: 24 к/с, звук AAC 48 кГц, готово за 1–3 минуты. Отказ модерации и ошибка до старта денег не стоят.
В прайсе провайдера есть похожее имя `video_omni` — это другая модель (Kling Omni) с ценой ¥1,05 **за секунду** и предоплатой. Скрипт её не запускает, вручную тоже не надо.

## Перед первым запуском
1. Ключ: файл `.env` в корне набора со строкой `YICIYUANG_API_KEY=sk-...` (как получить — `guides/registration.md`). Ключ никогда не печатать в чат и не коммитить.
2. `python3 scripts/omni.py check` — бесплатно, покажет, какие модели доступны на ключе.
3. Нужен `ffmpeg` (для подготовки и склейки). Нет — поставить: macOS `brew install ffmpeg`, Windows `winget install Gyan.FFmpeg`, Linux `sudo apt install ffmpeg`.

## Как скрипт передаёт видео
Провайдер не принимает файлы с диска, только **публичную ссылку на mp4**. `omni.py run` сам выкладывает локальный файл во временное хранилище: по умолчанию `uguu.se` (файл удаляется через 3 часа), запасной `--host litterbox` (catbox, 1 час; из некоторых сетей отвечает «Invalid uploader»). Вместо пути можно дать свою ссылку `https://...mp4`.
Скажи пользователю один раз: файл на 3 часа станет доступен по случайной ссылке. Чужие лица и приватное видео без согласия не выкладывать.

## Правило денег
Перед каждым платным запуском назови цену (число запусков × цена) и жди «да». `--dry-run` показывает запрос и цену бесплатно. Повторный запуск с тем же именем не платит второй раз: скрипт дозабирает готовый результат по `out/<имя>.ledger.json`.

## Рецепт 1. Продлить видео
1. Подготовить вход (≤ 12 с, конец на конце фразы):
   `python3 scripts/omni.py prep source.mov clip.mp4 --start 0 --dur 10`
2. Запрос — короткий и по-английски, без описания сцены и без таймингов:
   ```
   The woman continues speaking to the camera. She says in Russian, word for word: "<что сказать дальше>"
   ```
3. `python3 scripts/omni.py run ext1 --model omni-extend-20s --prompt-file p.txt --video clip.mp4 [--image face.jpg]`
   Фото лица (`--image`) помогает держать внешность при поворотах.
4. Взять только новое: `python3 scripts/omni.py newpart out/ext1.mp4 clip.mp4 ext1_new.mp4`
5. Склеить: `python3 scripts/omni.py join clip.mp4 ext1_new.mp4 -o final.mp4 --delogo`

**Длинный ролик цепочкой (30–60+ с):** каждый следующий шаг получает **последние 11,9 с** предыдущего результата:
`prep out/ext1.mp4 tail1.mp4 --tail 11.9` → `run ext2 ... --video tail1.mp4` → `newpart out/ext2.mp4 tail1.mp4 ext2_new.mp4` → и так далее. В конце `join clip.mp4 ext1_new.mp4 ext2_new.mp4 ... -o final.mp4`. Минута ≈ 5 шагов ≈ ¥3,75 (~45 ₽).

Что знать про продление:
- **Текст пересказывает своими словами**, тему держит, визуальные указания («показывает три пальца») выполняет точно. Дословно говорит только `omni-fast-no-water`.
- Длинный вход (10–12 с) держит русский язык и голос лучше, чем короткий (5 с).
- Брак примерно в 1 из 3: фраза повторяется дважды, в конце бессмыслица. Каждый шаг смотреть и слушать; плохой шаг перезапустить под новым именем (2 варианта параллельно).
- На стыке не должно быть слов: реплика заканчивается за 1–1,5 с до конца куска. Резких движений на стыке тоже не нужно.
- Отказ «identifiable real person» бывает на реальных лицах. Фото ради прохода модерации не менять: это обход правил провайдера.

## Рецепт 2. Перерисовать видео (одежда, фон, стиль)
1. Кусок ≤ 10 с: `python3 scripts/omni.py prep source.mov c01.mp4 --start 0 --dur 9.8`
2. Запрос — «оставь всё как есть» + «единственное изменение»:
   ```
   Video-to-video edit. Keep EVERYTHING exactly as in the source video: the same person, face, hair, expressions, lip movements and speech, the same hands and every gesture with identical timing, the same background, lighting, colors, camera framing and motion. Do not add any text, logo or watermark.
   The ONLY change: <точное описание: replace her green apron with a classic black leather jacket over a white t-shirt>. Identical on every frame, moves naturally with the body. Photorealistic.
   ```
   Для стиля: `The ONLY change: render the whole video in Modern Disney 3D animation style (Zootopia, Encanto), keep the same person likeness, motion and speech.`
3. `python3 scripts/omni.py run v01 --model omni-fast-v2v --prompt-file p.txt --video c01.mp4 [--image ref.jpg]`
4. Видео длиннее 10 с — резать на куски по паузам в речи (не ровно по 10 с!), каждый кусок с одним и тем же `--image` (кадр удачного первого результата), потом `join ... --delogo`.

Что знать про перерисовку:
- Модель **перерисовывает весь кадр**, а не только одежду: жесты повторяет примерно, лицо чуть другое.
- **Речь синтезирует заново** тем же текстом и сдвигает (до 1,3 с). Подложить исходный звук нельзя — губы разъедутся. Поменять слова через v2v тоже нельзя: губы останутся старыми.
- На краях куска может оборвать слово или съесть его — режь по паузам, проверяй стыки на слух.
- Справа внизу бывает значок Gemini — `join --delogo` его затирает.
- Кусок без звука v2v превращает в продление тишины — давай видео со звуком.

## Рецепт 3. Ролик из фото (дословная реплика)
Промпт — по формуле из раздела «Формула промпта с речью» ниже, пример в `examples/photo-scene.txt`.
`python3 scripts/omni.py run scene1 --model omni-fast-no-water --prompt-file p.txt --image face.jpg`
Годится как старт для цепочки продлений и для смены плана посреди ролика (новая сцена с последнего кадра).

## Рецепт 4. Ролик по раскадровке (сценарий → кадры → видео)
Так результат виден до платных запусков, а каждая сцена заканчивается там, где задумано.
1. **Сценарий.** Сцены по 10 с, на сцену одна мысль и 14–18 слов. В репликах без тире и дефисов (модель их «озвучивает»), числа словами.
2. **Раскадровка.** На каждую сцену минимум два кадра — первый и последний, лучше пять (0, 2, 4,5, 7 и 9,5 с). Картинки 16:9, от 1280×720. Делаются любым генератором картинок, который есть у пользователя, или берутся свои фото. Правила:
   - первый кадр сцены — по фото человека, с одним и тем же описанием одежды во всех сценах;
   - остальные кадры сцены — от первого кадра как от образца: «та же локация, свет, одежда и ракурс, меняются только поза и жест»;
   - на последнем кадре рот закрыт: речь заканчивается раньше конца клипа.
3. **Показать раскадровку пользователю и дождаться «да».** Только потом платные запуски.
4. **Видео.** Одна сцена — один запуск с двумя кадрами (пример промпта — `examples/two-frames.txt`):
   `python3 scripts/omni.py run s1 --model omni-fast-no-water --prompt-file s1.txt --image s1_first.jpg --last-image s1_last.jpg`
   Промпт начинается с `Use the first image as the first frame and the second image as the last frame.`, дальше — та же формула с речью. Жесты промежуточных кадров описываются словами.
5. **Склейка.** У каждого клипа обрезать тишину до первого и после последнего слова (`prep --start … --dur …`), потом `join`.

Что знать про два кадра:
- Клип начинается с первого кадра и заканчивается на втором: проверено на 6 сценах из 6 (ноябрь 2026).
- Если ракурс у кадров разный, в конце будет монтажная склейка, а не плавное движение. Для одного дубля держите один ракурс.
- Цена та же: ¥0,75 за сцену.

## Формула промпта с речью (для рецептов 3 и 4)
```
In a single continuous shot, no scene cuts. Horizontal 16:9. Use the image as the first frame. <одно движение камеры>. <кто> keeps the exact face from the image and the same <одежда>. [0-2s] <что делает молча>, lips closed. [2-9.5s] <He/She> speaks briskly, at a fast energetic pace, and says in Russian: <реплика 14–18 слов, БЕЗ кавычек> <один жест>. <He/She> finishes the phrase before the clip ends. [9.5-10s] <что делает молча>, no speech. Sound: the voice over clearly audible <фон: light wind / quiet room tone>. No music. No subtitles, no captions, no on-screen text, no logos.
```
- Реплика идёт после двоеточия **без кавычек**, первые 2 секунды без слов. По этой формуле 12 клипов из 12 сказали текст дословно и без повторов; та же реплика в кавычках с речью с первой секунды дала повтор слов в 2 дублях из 3.
- Движение камеры — ровно одно: `The camera remains static` / `the camera dollies backward smoothly at his pace` / `The camera slowly orbits about a quarter turn around him` / `One slow push-in from a medium shot to a medium close-up`.
- Лицо и фон с кадра не пересказывать: достаточно `keeps the exact face from the image`.
- Вертикальный ролик: `Vertical 9:16.` и `--size 720x1280`.

## Проверка результата (обязательно перед выдачей)
- `ffprobe` — длительность и размер.
- Кадры каждые 0,5 с листом: `ffmpeg -i final.mp4 -vf "fps=2,scale=-2:160,tile=10x6" -frames:v 1 sheet.jpg` — посмотреть глазами: лицо, одежда, стыки, лишние предметы.
- Послушать или распознать речь любым сервисом: нет ли повторов, обрывов, английского вместо русского. Распознавание иногда прячет повтор внутри одного «длинного» слова: слово дольше секунды — переслушать это место.

## Ошибки и что делать
| Ответ | Причина | Что делать |
|---|---|---|
| `insufficient_user_quota` | кончился баланс | пополнить на сайте |
| `Source video is too long` | вход > 12 с | `prep --dur 10` или `--tail 11.9` |
| `image_rejected`, `identifiable real person` | модерация | другое фото; не пытаться обмануть фильтр |
| `No available channel for model` | канал модели временно выключен | подождать или другая модель |
| `previously flagged by content policy (md5=…)` | после отказа модерации провайдер навсегда блокирует сам файл картинки | взять другой кадр или фото; перекодировать файл ради обхода нельзя |
| отказ на призыве («подпишись», «пиши слово…») с лицом в кадре | реклама устами узнаваемого человека | сделать призыв закадровым голосом поверх кадра без лица: `An off-screen voiceover says in Russian: …`, `the face is never visible` |
| `хранилище ... отказало` | временное хранилище не приняло файл | `--host litterbox` или своя прямая ссылка на mp4 |
| долго нет результата | очередь | тот же запуск ещё раз — дозаберёт без новой оплаты |

## Нельзя
- Печатать ключ, класть его в код, коммитить `.env`.
- Запускать платное без названной цены и «да» пользователя.
- Склеивать `ffmpeg -f concat` (у кусков разная временная база, видео уходит в чёрный экран) — только `omni.py join`.
- Подменять звук v2v исходным.
- Выкладывать чужое лицо без согласия.
