# omni-video-kit — продлить и перерисовать видео нейросетью за 9 ₽

Скилл для вашего ИИ-агента: он научится продлевать любое видео (хоть до минуты цепочкой), переодевать человека в кадре, менять фон и стиль (Disney, аниме, нуар) и оживлять фото — через Google Omni у провайдера 创艺坊 (Yiciyuang). Один запуск — ¥0,75–0,82 (≈ 9–10 ₽).

## Как начать (1 минута)
Вставьте своему агенту (Claude Code, Codex, Antigravity, Cursor — любому агенту с терминалом):

```
Склонируй репозиторий https://github.com/PavelDumbrao/omni-video-kit, прочитай AGENTS.md и выполни всё, что там написано: установи себе скилл omni-video-edit и проведи меня до первого готового видео.
```

Агент поставит скилл, проверит ffmpeg, попросит ключ и проведёт до первого ролика. От вас — ключ, видео или фото и «да» перед платным запуском.

## Что умеет
| Задача | Модель | Цена |
|---|---|---|
| Продлить видео на ~10 с (цепочкой — 30, 60 с и больше) | `omni-extend-20s` | ¥0,75 за шаг |
| Переодеть, сменить фон или стиль куска до 10 с | `omni-fast-v2v` | ¥0,82 за кусок |
| Ролик 10 с из фото, человек говорит вашу фразу дословно | `omni-fast-no-water` | ¥0,75 |
| Ролик по раскадровке: каждая сцена идёт от первого кадра к последнему | `omni-fast-no-water` | ¥0,75 за сцену |

Минута непрерывного видео цепочкой продлений ≈ ¥3,75 (≈ 45 ₽).

## Что понадобится
- Аккаунт и ключ на https://newapi.yiciyuang.com/register?aff=W3q1 — по шагам в `guides/registration.md`, баланс ¥10–20 на пробы.
- Python 3.9+ и ffmpeg (агент поставит сам).

## Структура
```
AGENTS.md                      инструкция агенту: установить скилл и вести за ручку
skills/omni-video-edit/SKILL.md  сам скилл: модели, рецепты, промпты, ошибки
scripts/omni.py                скрипт: check, prep, run, newpart, join (только стандартный Python)
examples/                      проверенные промпты: продление, переодевание, стиль, сцена из фото, сцена между двумя кадрами
guides/registration.md         регистрация, ключ, пополнение
guides/my-voice.md             свой голос в ролике: ElevenLabs speech-to-speech
```

## Важно
- Провайдеру нужна публичная ссылка на файл: скрипт сам выкладывает видео на uguu.se (удаляется через 3 часа). Чужие лица и приватное видео без согласия не загружайте.
- Перерисовка заново синтезирует речь, продление пересказывает текст своими словами — подробности в скилле.
- Для ролика из нескольких сцен сначала сценарий и раскадровка, потом видео: так результат виден до оплаты (рецепт 4 в скилле).
- Ключ хранится только в `.env`, который не попадает в git.
